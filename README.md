## 🎯 The "Why": Project Purpose & Core Objectives

### 1. Digital Atelier Experience vs. Traditional E-Commerce
Traditional furniture e-commerce platforms suffer from visual clutter—infinite search bars, overwhelming shopping carts, discount stickers, and low-trust stock imagery. Heaven Furniture Mart requires the digital equivalent of **stepping into a serene, high-end private interior studio**—clean spatial hierarchy, refined warm ivory backgrounds, and editorial imagery that lets fine woodwork speak for itself.

### 2. The 30-Second Golden Trust Rule
A homeowner investing in bespoke teak or mahogany furniture often has high expectations and initial hesitation. Within the first 30 seconds of landing on this page, a visitor who has never heard of Heaven Furniture Mart immediately recognizes:
- An established physical flagship showroom on Agrabad Access Road.
- Verifiable institutional milestones and national chamber memberships (2020–2026).
- 10-year timber warranties against termite and borer infestation.
- Verbatim leadership endorsement from the Managing Director and genuine client reviews.

### 3. Frictionless WhatsApp Conversion Flow
Bespoke furniture cannot be bought with an impersonal "Add to Cart" button. Every purchase requires room dimension audits, fabric swatches, wood grain selection, and 3D rendering consultations. Every primary Call-To-Action (CTA) across the page routes directly to the showroom's senior styling desk via **WhatsApp (`+880 1960-481983`)** for instantaneous consultation.

## 💻 Local Development Setup

Follow these simple steps to run the application on your local machine:

### 1. Clone the repository and navigate to the project:
```bash
cd hackathon
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Start the local development server:
```bash
npm run dev
```
Open your browser and navigate to [http://localhost:3000](http://localhost:3000) (or the port specified in terminal).

### 4. Validate code quality (ESLint):
```bash
npx eslint src
```
*(Confirms 0 errors and 0 warnings across all files)*

### 5. Create a production build:
```bash
npm run build
```
