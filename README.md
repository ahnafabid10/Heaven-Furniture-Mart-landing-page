## 📖 Project Overview

**Heaven Furniture Mart** is one of Chattogram's leading bespoke luxury furniture and architectural woodwork studios. Founded in 2020 by Managing Director **Abul Kalam Bhuiyan**, the brand rejects mass-produced, flat-pack furniture. Instead, every piece—from hand-carved royal bed suites and Chesterfield velvet lounges to solid teak dining suites and executive boardroom desks—is custom-sculpted around the client's room dimensions, architectural blueprints, and personal aesthetic.

This project delivers a **state-of-the-art, conversion-optimized digital atelier** designed for the **RACDOX HACKATHON**. Rather than resembling a cluttered retail shop, the landing page is structured to feel like walking through the doors of a high-end physical interior design studio.

## 🎯 The "Why": Motivation, Problem Statement & Objectives

### 1. The Problem with Traditional Furniture E-Commerce
Most online furniture stores are designed around mass-market consumer behavior: infinite catalog grids, discount badges, "Add to Cart" buttons, and price wars. However, high-net-worth homeowners, architects, and luxury interior clients **do not purchase bespoke furniture off a retail shelf**. They require:
- Tactile material confidence (genuine solid seasoned timber, authentic grain, luxury upholstery swatches).
- Architectural verification (room measurements, doorway clearance audits, 3D renderings).
- Institutional trust (physical showroom presence, established history, structural warranties).

### 2. The 30-Second Golden Trust Rule
A prospective client visiting Heaven Furniture Mart for the first time will decide within 30 seconds whether the brand is a credible atelier or an unverified online reseller. The website solves this by immediately presenting:
- Prominent branding and physical showroom coordinates on Agrabad Access Road.
- Verified chronological milestones (2020 founding, Agrabad multi-story showroom, Chamber of Commerce membership, national BFIOA recognition).
- Ironclad quality guarantees: **10-Year Anti-Borer & Termite Guarantee** and **5-Year Structural Joint Warranty**.
- Verbatim leadership philosophy from Managing Director Abul Kalam Bhuiyan alongside authentic homeowner reviews from premier Chattogram residential areas (Khulshi, Nasirabad, Agrabad).

### 3. Frictionless Conversion Architecture
Because bespoke furniture requires personalized collaboration, traditional checkout forms create drop-off. This project implements a **zero-friction direct conversion funnel**: every key touchpoint ("Book Free Design Consultation", "Free Consultation", direct phone numbers, and showroom hotline) routes straight into an active WhatsApp chat with the Senior Stylist at **`+880 1960-481983`** (`https://wa.me/8801960481983`).

## 💻 Getting Started & Local Development Setup

To run this project locally, ensure you have **Node.js 18+** and **npm** installed:

### 1. Clone the repository and navigate into the project directory:
```bash
cd hackathon
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Start the local development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the port indicated in your console) in your browser.

### 4. Verify code quality (Linting):
```bash
npx eslint src
```
*(Currently validated with **0 errors and 0 warnings**)*

### 5. Build for production:
```bash
npm run build
```
